# ЭРА ПК на Rust — era-pc-rust

Экспериментальные расчёты выбросов и рассеивания на Rust.
Неофициальный исследовательский проект, не связанный с разработчиком ПК ЭРА.
Это пока **не полная замена ЭРА**. Модуль рассеивания написан независимо
по части формул МРР-2017; защищённое ядро оригинала не восстановлено.

## Для Windows

Готовые EXE пока не публикуются: ни в Releases, ни в артефактах Actions.
CI собирает и проверяет Windows-программу только внутри сборочного окружения.
Публичный исполняемый пакет будет выпущен после готовности полноценного ПО
для пользователей и отдельного решения о релизе, а не как демонстрация ядра.
Сейчас доступны исходники и тесты для разработки. Целевой интерфейс — CLI,
включая Windows; оконная оболочка не требуется для релиза.
Критерии готовности зафиксированы в [плане](docs/ROADMAP.md#публикация).

## Быстрый старт

Для сборки проверен Rust 1.90.0. Оригинальные файлы ЭРА не нужны:

```sh
cargo test --locked
cargo run --locked -- demo
cargo run --release --locked -- dispersion examples/dispersion.json
cargo run --release --locked -- dispersion-search examples/dispersion-search.json
cargo run --release --locked -- dispersion-compare examples/dispersion-reference.json
cargo run -- --help
```

`demo` выполняет специально написанный учебный расчёт: 1 г/с и 3,6 т за
1000 часов. Это проверка исполнителя, а не нормативная методика.

## Что работает

- Рассеивание от вертикальных точечных источников: Cm, Xm, Um, тёплая и
  холодная ветви, концентрации в заданных точках при заданных ветрах,
  суммирование нескольких труб. [Область применимости и формат](docs/DISPERSION.md).
- Поиск ветра по уточняемым сеткам с историей улучшений и явным статусом остановки.
- Сравнение фиксированных концентраций с эталоном через CLI.
  [Как будем сверять с ЭРА](docs/VALIDATION.md): реальных выгрузок оригинала пока нет.
- Числа, строки, логические выражения, условия, переходы и циклы.
- Таблицы и словари, явный выбор строки, поиск по условиям.
- Числовые диапазоны, выбор значения через `_Diap_` и проверка принадлежности.
- Массивы, групповые присваивания, суммы и максимумы по строкам/столбцам.
- Независимые пакетные расчёты в нескольких потоках с сохранением порядка.
- Трассировка и сообщения об ошибках с методом, строкой и номером записи.

Локально проверены отдельные пути четырёх извлечённых методик и отдельные
формулы пятой. Успешный синтаксический разбор не означает полного исполнения.

## Локальные данные

В репозитории **нет** установщика, EXE/DLL, извлечённых алгоритмических баз,
таблиц коэффициентов или руководств стороннего продукта. Эти материалы
необходимы только для локальных проверок на соответствующем корпусе.

```sh
export ERA_DATA=/absolute/path/to/recovered
cargo run --release -- run examples/washing.json
cargo run --release -- run-batch examples/batch.json 3
cargo run --release -- audit
cargo test --locked --features recovered-tests
```

В PowerShell: `$env:ERA_DATA = 'C:\path\to\recovered'`.
`recovered-tests` — явное включение локальных корпусных тестов: они завершатся
ошибкой без базы, а не будут незаметно пропущены. Обычный CI не включает этот режим.

Формат входов и ограничения описаны в [README.txt](README.txt).
Архитектура и план развития — [docs/ROADMAP.md](docs/ROADMAP.md).

## Ограничения

Защищённое ядро рассеивания и внешние функции оригинала не восстановлены.
В независимом модуле рассеивания пока нет застройки, сложного рельефа, фона,
среднегодовых расчётов. Поиск ветра экспериментальный, без гарантии глобального
максимума и без сверки с оптимизатором ЭРА.
Не воспроизведены все правила округления, накопления выбросов и изменения
проектных баз. `writes` — события присваивания, не итоговая инвентаризация.
Неизвестные функции и неоднозначные метки не заменяются догадками.

Не используйте экспериментальные результаты как проверенный нормативный расчёт.
Полноценной численной сверки с работающим оригиналом пока нет.

## Разработка

```sh
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
```

CI настроен для Linux, Windows и macOS; успешность удалённых запусков следует
проверять в Actions, а не выводить из наличия workflow. Изменения фиксируются
обычными тематическими коммитами без переписывания истории.

Публичная лицензия пока не выбрана владельцем проекта. Наличие исходников
не означает предоставления лицензии на материалы стороннего продукта.
