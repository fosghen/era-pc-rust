ЭРА ПК на Rust: экспериментальный расчёт рассеивания, 0.2.0-alpha.1

Это независимый неофициальный проект, не продукт разработчика ЭРА.
Это НЕ полная замена ЭРА и НЕ проверенное нормативное ПО.

БЫСТРЫЙ ЗАПУСК (Windows x64)
1. Распакуйте весь ZIP в отдельную папку, доступную для записи.
2. Дважды нажмите run-dispersion.cmd — он рассчитает учебный пример.
3. Результат появится рядом в новом файле result-<числа>.json.
4. Для своего расчёта скопируйте examples\dispersion.json, измените
   параметры в текстовом редакторе (сохранение UTF-8 без BOM).
   Перетащите свой JSON на run-dispersion.cmd.

Или из PowerShell в папке программы:
  .\era-engine.exe dispersion .\examples\dispersion.json
Вывод можно сохранить: добавьте > result.json (существующий файл заменится).
Rust, исходные файлы ЭРА и USB-ключ для этого модуля не нужны.
Пакет не содержит установщика и не требует прав администратора.
Целевой интерфейс — CLI: ввод и вывод — JSON, оконный редактор не планируется.
Дополнительные команды (из PowerShell):
  .\era-engine.exe dispersion-search .\examples\dispersion-search.json
  .\era-engine.exe dispersion-compare .\examples\dispersion-reference.json
Вторая команда проверяет учебный эталон по формулам, НЕ выгрузку ЭРА.
EXE не подписан сертификатом; не отключайте антивирус для его запуска.

ЧТО РАССЧИТЫВАЕТСЯ
Одна примесь, одна или несколько вертикальных труб, ровная местность.
Круглое/прямоугольное устье, тёплый/холодный выброс с положительной
скоростью выхода; Cm, Xm, Um; приземные концентрации в заданных точках
при заданных скоростях и направлениях ветра, сумма вкладов труб.
Максимум выбирается ТОЛЬКО среди заданных вариантов ветра.

ВАЖНО
Коэффициенты A и F задаёт специалист. Координаты в метрах: X на восток,
Y на север; ветер задаётся ОТКУДА дует (180 градусов — с юга).
Выброс г/с, концентрации мг/м3, температуры °C, скорости м/с.
Высота расчётных точек — строго 2 м. Температура газа не ниже воздуха.
См. docs\DISPERSION.md: все поля, ограничения и проверки.

Пока НЕТ: застройки, сложного рельефа, фона, трансформации веществ,
линейных/площадных источников, среднегодовых концентраций, гарантированного
глобального максимума по ветру, сравнения с ПДК,
загрузки проектов оригинальной ЭРА и подтверждённого совпадения с ней.
Не применять результат для официальной отчётности без независимой проверки.
