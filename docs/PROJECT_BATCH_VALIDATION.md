# Дополнительная подборка проектов — 20.10.2026

Получены три локальных проекта. Здесь используются только их условные метки;
названия объектов, координаты и численные fixtures остаются приватными.
Расчётное ядро не менялось, оригинальные EXE не запускались.

## Какие условия сохранены

Во всех 72 найденных управляющих файлах включены автоматический поиск
направления/скорости ветра и сезон Max. Фиксированного ветра в этой подборке
управляющих файлов не обнаружено. Поэтому проекты расширяют набор проверок
параметров источников, но не дают точного фиксированного ветра для сверки поля.

В RESNEW находятся 66 таблиц Cm/Um/Xm: 26, 25 и 15 соответственно.
Из них 18 относятся к группам суммации. Остальные содержат 118 пар
«вещество–источник», включая 50 площадных.

## Строгие результаты

Сохраняются два профиля из [предыдущей проверки](PROJECT_SOURCE_VALIDATION.md):
буквальная скорость из входа и восстановление скорости из V1/D с обязательной
проверкой её согласованности с печатной точностью исходной скорости.

| Проект | Буквальная скорость: совпало / сравнено | Согласованный расход: совпало / сравнено |
| --- | ---: | ---: |
| G202 | 5 / 11 | 10 / 10 |
| G212 | 0 / 7 | нет допущенных случаев |
| G398 | нет допущенных случаев | нет допущенных случаев |

Сравнение каждого случая охватывает Cm/ПДК, Um и Xm с допуском половины
последнего разряда отчёта. Ноль допущенных случаев не является успешной проверкой.

Исключения во втором профиле:

| Причина | G202 | G212 | G398 |
| --- | ---: | ---: | ---: |
| Газ холоднее воздуха | 34 | 9 | 0 |
| Площадной источник | 18 | 16 | 16 |
| Расход и скорость не согласуются в пределах округления | 1 | 7 | 0 |
| Скорость выше ограничения текущего ядра 330 м/с | 0 | 0 | 7 |
| Отчёт по группе суммации | 5 | 9 | 4 |

Первые четыре строки считают пары «вещество–источник»; последняя — отчёты
по группам. Повторы одного физического источника для разных веществ не являются
независимыми конфигурациями.

## Отдельная гипотеза о приоритете расхода

Для одной конфликтующей пары G202 и семи пар G212 проведён отдельный
диагностический эксперимент: скорость вычислена по V1 и D, несмотря на
несогласованность с исходной скоростью. Формулы, температуры, выбросы и
допуски не менялись; ограничение скорости ядра сохранено.

Все восемь диагностических случаев совпали по трём параметрам.
В G202 восстановленная скорость больше исходной примерно в 5.17 раза,
в G212 — в 1.389 раза. Это существенно больше ошибки округления.

Результат поддерживает гипотезу, что сохранённые расчёты согласованы с расходом
как определяющим входом. Он не доказывает актуальность данных, правильность
значений или точный внутренний путь вычисления ЭРА. Эти восемь случаев
**не добавлены к строгим успешным проверкам**. Автоматический импорт по-прежнему
не исправляет конфликтующие входы.

## Улучшение инструмента

Раньше источник со скоростью выше 330 м/с мог попасть в fixture и затем
прервать весь Rust-прогон с ошибкой валидации. Теперь extractor исключает его
с явной причиной до запуска сравнения. Отдельно различаются неподдерживаемые
высота, рельеф, нулевой поток и отрицательная разность температур.
Никакого снятия ограничения или подмены отрицательной разности на ноль нет.

Добавлены синтетические тесты превышения/границы скорости и отрицательной
разности температур. Прочитанные для сверки 288 файлов проектов повторно
проверены по хешам — изменений нет.

## Следующий полезный эталон

Для проверки именно поля нужен сохранённый расчёт с фиксированными ветром
и высотой рецептора. Для исследования конфликтов входа полезны отдельные
варианты одного источника с явно согласованными D, V1 и w0. Существующие
проекты остаются материалом для проверки площадных источников, холодных
выбросов и групп суммации после расширения ядра.
