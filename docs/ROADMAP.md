# Архитектура и план

`data.rs` загружает локальную JSON-модель; `expr.rs` разбирает язык;
`engine.rs` исполняет программу в изолированном состоянии; `lib.rs` запускает
пакеты; `main.rs` предоставляет CLI. `demo.rs` не использует сторонние данные.

## Критерии достоверности

У каждого расширения нужны источник семантики и тест. Различаем:
восстановленный текст, синтаксически разобранный текст, исполненный путь,
сравнение с независимой формулой и сравнение с оригинальной программой.
Эти уровни не взаимозаменяемы. Производительность измеряется только для
конкретного сценария; микротест не характеризует скорость всей ЭРА.

## Публикация

Коммитить только исходники проекта, синтетические тесты и документацию.
Не добавлять оригинальные программы, извлечённые базы, ключи, секреты или
проектные данные. Не включать локальные корпуса в CI-артефакты.
Перед push проверять `git diff --cached --stat` и список отслеживаемых файлов.
